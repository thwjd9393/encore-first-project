# Repository instructions

Before implementing or reviewing PlayEAT, read `AI_IMPLEMENTATION_GUIDE.md` and every required reference it lists. Treat `PRD_개정본.md` as the functional contract, `design.md` as the shared UI contract, `API_설계서.md` as the HTTP contract, and the `정의서_new` sheet in `encore_project.xlsx` plus approved PRD changes as the database contract.

The frozen implementation baseline is `PRD-BASELINE-1.0`. Do not expand its scope.

Follow the document priority defined in `AI_IMPLEMENTATION_GUIDE.md`. Do not invent features, API shapes, database fields, facts, or page-specific visual styles. Every completed change must identify the related PRD requirement, P1 criterion, and M0~M9 stage and report the validation performed.
