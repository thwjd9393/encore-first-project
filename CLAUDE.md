# PlayEAT project instructions

Read `AI_IMPLEMENTATION_GUIDE.md` before starting work and follow its complete reference order. Use `PRD_개정본.md` for functions and business rules, `design.md` for shared UI rules, `API_설계서.md` for HTTP contracts, and the `정의서_new` sheet in `encore_project.xlsx` plus approved PRD changes for database contracts.

The frozen implementation baseline is `PRD-BASELINE-1.0`. Do not expand its scope.

Do not invent missing features, API fields, database columns, facts, or visual styles. Relate each implementation to the applicable PRD requirement, P1-1~P1-4 criterion, and M0~M9 stage, then report the validation evidence.
